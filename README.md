# 台灣麻將 · 連線對戰

**[👉 立即遊玩](https://7uuuuuuutw.github.io/taiwan-mahjong/)**（免安裝，開房後把房號給朋友即可一起玩）

## 怎麼玩

麻將要用 PeerJS 連線，網頁需要透過「本機伺服器」開啟（直接雙擊 `index.html` 用 `file://` 開可能無法連線）。

### 啟動本機伺服器

在 `taiwan-mahjong` 資料夾下執行任一種：

```bash
# Python（大多數電腦內建）
python -m http.server 8123

# 或 Node
npx http-server -p 8123
```

然後瀏覽器開 `http://localhost:8123`。

### 開始遊戲

1. 輸入暱稱 → 按「開新房間」，會得到一組房號（也可自訂）。
2. 朋友在自己的瀏覽器開同一個網頁，輸入房號按「加入房間」。
   - 要跨網路一起玩，房主這台需要能被連到（同一 Wi-Fi 最簡單；跨網路可用 ngrok 之類工具或部署到雲端）。
3. 房主按「開始遊戲」，不足 4 人的空位自動由電腦補上。

## 功能一覽

- **P2P 連線對戰**：PeerJS (WebRTC)，房主的瀏覽器當遊戲主機；斷線會自動暫停並嘗試重連。
- **電腦補位**：多種個性角色，會依牌局情境冒出對話、各自帶不同打牌風格；電腦強度可調。
- **完整台灣 16 張規則**：涵蓋常見台數、特殊胡牌情境與細節限制——遊戲內大廳的「📜 特殊規則速查」有完整整理，這裡不重複劇透。
- **房間設定**：底/台、出牌計時、電腦強度、牌背顏色、哩咕與骰子加成開關、座位調整等皆可自訂。
- **拖曳打牌、逐手倒數、音效與語音報牌**。
- **回等待室**：一局結束可留在同個房間直接開新的一場。
- **遊玩統計 / 意見回饋**：大廳可查看本機遊玩紀錄、回報問題。

## 已知限制

- 極罕見牌型（天胡、地胡、十三么等）尚未納入。
- 房主關掉瀏覽器該局即結束；PeerJS 用免費公共媒合伺服器，偶爾可能不穩。

| `network.js` | PeerJS 連線層 |
| `main.js` | UI 與流程整合 |
