# 台灣麻將 · 連線對戰

16 張台灣麻將網頁，支援 P2P 連線對戰與電腦 AI 補位。

## 怎麼玩

麻將要用 PeerJS 連線，網頁需要透過「本機伺服器」開啟（直接雙擊 `index.html` 用 `file://` 開可能無法連線）。

### 啟動本機伺服器

在 `taiwan-mahjong` 資料夾下執行任一種：

```bash
# Python（大多數電腦內建）
python -m http.server 8123

# 或 Node
npx http-server -p 8123
```

然後瀏覽器開 `http://localhost:8123`。

### 開始遊戲

1. 輸入暱稱 → 按「開新房間」，會得到一組 4 碼房號。
2. 朋友在自己的瀏覽器開同一個網頁，輸入房號按「加入房間」。
   - 要跨網路一起玩，房主這台需要能被連到（同一 Wi-Fi 最簡單；跨網路可用 ngrok 之類工具或部署到雲端）。
3. 房主按「開始遊戲」，不足 4 人的空位自動由電腦補上。

## 功能

- **連線**：PeerJS (WebRTC) P2P，房主的瀏覽器當遊戲主機（權威狀態）。
- **AI 補位**：空位由電腦頂上，1～3 個真人也能開打。**20 個個性角色**隨機登場（旺來伯、阿花姨、雀聖、紅中俠、發財哥、骰神、月光姐、海底撈、龜速伯、小辣椒、阿吉師、風火輪嫂、錦鯉妹、老棋王、一色痴、拼場霸、抓藥仙、衝浪弟、賭神嫂、隱士翁），會在碰吃槓胡、補花、流局、詐胡等情境冒出對話泡泡（純演出不影響遊戲）。
- **偏好打法**：每個角色帶一種打牌傾向——**積極型**（阿花姨、紅中俠、小辣椒、阿吉師、拼場霸）逢碰必碰搶進度；**求快型**（風火輪嫂、衝浪弟）拚命衝向聽牌；**穩健防守型**（雀聖、月光姐、龜速伯、老棋王、抓藥仙）重視安全牌、碰吃更保守；**大牌型**（發財哥、海底撈、一色痴、隱士翁）偏好追一色、寧可拆碰也要護住門清；**賭性型**（旺來伯、骰神、錦鯉妹、賭神嫂）決策帶隨機性、愛衝愛博。困難模式下差異最明顯。
- **發牌演出**：莊家擲骰後**先讓大家看清楚骰子定案結果**，才開始各家自莊家起輪流抓 4 張（共 4 輪）、再依序補花，全由電腦自動進行。**豹子**（三顆同數）會有骰盅發光＋全螢幕「豹子！」大字閃現，格外醒目。
- **拖曳打牌**：輪到你時按住牌往上拖到中央「放開打出」區即可打出，拖不到位會彈回避免誤打；也可輕點快速打出。支援滑鼠與觸控。摸上來的牌會分開放在最右邊並發金光。
- **每手計時**：輪到你行動時右上角顯示倒數（出牌 20 秒、吃碰槓胡 15 秒），逾時自動隨機打一張。
- **音效**：合成的打牌聲與胡牌音階，並用瀏覽器語音報「碰／吃／槓／胡／自摸」；右上角 🔊 可靜音（全部內建，離線可用）。
- **規則**：發牌、補花、摸打、吃、碰、明槓、暗槓、加槓、搶槓、自摸、放槍胡、流局、連莊換莊。**禁止槓上家**（上家打出的牌不能明槓）。**牌尾保留 16 張**不摸（摸到剩保留區即流局），**每開一槓保留區 +1**；畫面顯示的「剩 N 張」為實際可摸張數。
- **骰子**：每局開始由**莊家親自按鈕擲骰**（AI 莊自動擲），骰數和決定**東風位**（正花對應）。**全紅**（皆 1/4）本局胡牌 +1 台；**骰歸**（等差 1）+2 台；**豹子**（三同）最終籌碼 ×3。**骰運可累積**：111/444 = 全紅＋豹子（+1 台且 ×3）。
- **房間設定**（開房者）：底/台（30/10、50/20、100/50、200/50、300/100）、出牌計時（20/10/5 秒或不計時）、**電腦強度**（簡單/普通/困難）、**牌背顏色**（綠/藍/紅/紫/黑）、**是否啟用哩咕**、**是否啟用骰子加成**（皆預設開啟）、↑↓ 調整座位順序。
- **電腦強度**：三個等級共用「向聽數＋進張數」評估（比單純孤張判斷精準許多）。**困難**額外開啟：吃／碰／槓一律以向聽數是否變差判斷（不會為了碰而拆散好牌）、吃牌自動挑最佳搭配，以及基礎防守（同分優先打別家已棄過的安全牌）。
- **明槓補牌不能自摸**：大明槓（吃別人棄牌）與加槓補的那張牌只能打出，不能自摸（槓上開花）；只有暗槓補牌才可以。
- **喰い替え限制**：吃／碰完的那一輪，不能立刻打出會讓這口吃/碰「白吃白碰」的牌（例如手牌 2345 吃 2 用 3、4 → 不能打 2、5；手牌 555 碰 5 → 不能打剩下那張 5），手牌會標示 ×。
- **電腦吃碰有反應延遲**：真人打出的牌，電腦要吃碰槓前會停頓約 0.65～0.95 秒才動作，讓大家看得到那張牌。
- **回等待室**：結束遊戲後可回等待室（房間與連線保留），調整設定直接再開新一場，不用重新建房。
- **常駐胡牌鈕**：右下紅色圓鈕隨時可按；牌未成按下 = **詐胡**，依自己最接近的聽牌台數賠付各家（付莊家再加莊家/連莊台），並讓出莊位。若當下根本沒有牌可讓你宣告胡牌（例如反應窗口已過、輪到別家），按下只會提示「目前沒有可以宣告的胡牌」，不會被誤判詐胡。
- **過水**：可胡而不胡（過水）後，要再打出一張牌才能恢復胡牌資格（含自摸）。
- **一炮三響**：同一張放槍牌多家同胡時全部成立，放槍者逐家賠付。
- **哩咕（八對半）**：7 對 + 1 刻，8 台（不可有吃碰槓；不另計門清，聽第 7 對成牌時單吊照算）。
- **座位調整**：等待室的 ↑↓ 可把玩家換到任何座位（含空位/電腦位），兩名玩家可坐對家。
- **台數**：自摸、門清、門清自摸、平胡（**需無花且聽雙頭**——中洞/邊張/單吊不算平胡）、碰碰胡、**中洞**、**邊張**、**哩咕 8 台**、清一色、混一色、字一色、大三元、小三元、大四喜、小四喜、三/四/五暗刻、三/四槓、圈風門風、**正花**、槓上開花、海底撈月、河底撈魚、搶槓、全求人、莊家、連莊等。**莊家胡牌或放槍**皆計莊家台，連莊 n 次再加 2n 台（共 2n+1）。放槍胡時，胡牌張所成之刻算明刻。
- **籌碼**：底 + 台×台值（預設 30/10，開房可選）。結算畫面**亮出胡牌者的牌**，並有「**結束遊戲**」按鈕可看總排名。

## 已知限制

- 台數判斷取一組合法拆牌計算，少數複合牌型可能有邊界誤差。
- 極罕見牌型（八仙過海、天胡、地胡、十三么等）尚未納入。
- 房主關掉瀏覽器該局即結束；PeerJS 用免費公共媒合伺服器，偶爾可能不穩。

## 檔案

| 檔案 | 說明 |
|------|------|
| `index.html` | 頁面結構（大廳／等待室／牌桌／結算） |
| `style.css` | 牌桌與牌的樣式 |
| `mahjong.js` | 牌組、胡牌／聽牌判斷、台數計算引擎 |
| `tiles.js` | 牌面繪製（筒→圓點、索→竹、萬／字／花） |
| `sound.js` | 操作音效與語音報牌 |
| `ai.js` | 電腦補位策略 |
| `game.js` | 牌局狀態機（權威，跑在房主端） |
| `network.js` | PeerJS 連線層 |
| `main.js` | UI 與流程整合 |
